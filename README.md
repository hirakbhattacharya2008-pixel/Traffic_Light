# Traffic_Light
🚦 **Traffic Light**

A simple interactive traffic light project built with HTML, CSS, and JavaScript.

📌 **About**

This project creates a basic traffic light interface with three lights: **Red, Yellow, and Green**.

Users can click the corresponding buttons to turn on a light. When a light is selected, the other lights are reset to gray and the selected light gets a glowing effect.

✨ **Features**

🔴 Red light button

🟡 Yellow light button

🟢 Green light button

Only one light is active at a time

Active light has a glow effect

Smooth transition effect

Simple and beginner-friendly JavaScript

🛠️ **Technologies Used**

HTML5

CSS3

JavaScript

⚙️ **How It Works**

The project uses JavaScript DOM manipulation to control the traffic lights.

When a button is clicked:

All lights are reset to gray.

The selected light changes to its corresponding color.

A glowing box-shadow effect is applied to the selected light.

▶️ **How to Run**

Clone this repository.

Open the project folder.

Open index.html in your web browser.

Click the Red, Yellow, or Green button.
